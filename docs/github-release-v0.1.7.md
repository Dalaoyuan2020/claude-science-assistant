# CSA v0.1.7：界面收口、三套外观与内置帮助

CSA v0.1.7 是 v0.1 系列的可用性与发布质量版本。它不改写已经验证的 Provider/Bridge 事务边界，而是在 v0.1.6 的端口、进程、沙盒出口和非门禁体检基础上，统一界面、补齐帮助、修正明暗对比，并把版本身份纳入打包硬门。

## 三个公开版本分别做了什么

| 版本 | 公开定位 | 主要变化 |
| --- | --- | --- |
| v0.1.5 | 三模型聚合与统一安全启动入口 | 单 Key 接入、三 Key 角色分工、方案切换、事务化 Bridge 应用，以及 Windows/WSL/Claude Science 的统一入口。 |
| v0.1.6 | 深度质检与“做减法” | 增加端口所有权、Bridge 内容身份、WSL 挂载阻塞和 HTTP/SOCKS 沙盒真实出口检测；把“能否打开”与“体检是否全绿”拆开，非门禁探针不再阻止主功能。 |
| v0.1.7 | 界面、帮助与发布收口 | 亮色终端、经典面板、深色面板共用同一功能 DOM；经典主控四键等宽；接入命名/重命名、两步删除、内置 FAQ/人工帮助、对比度和版本一致性回归。 |

开发中曾把这套 UI 标为未发布的 `v0.1.8 feature-candidate`。公开发布前按产品版本史重新编号为 v0.1.7；它不是一个已经发布过又被覆盖的 v0.1.8。

## 本版重点

1. **三套简洁外观**：亮色终端控制台、经典卡片、深色面板只改变呈现，不复制命令、不分叉 ALLOW/GRADE/WORK 状态机；选择写入启动器设置，重启后保持。
2. **自适应布局**：主容器按窗口宽度收放；经典与深色的主控、F1、F2、F3 保持等尺寸，小窗口自动改为两列/单列，弹窗在可视高度内滚动。
3. **明暗对比修复**：深色卡片统一使用浅色文字，激活态使用浅绿色底配深色字；同时修复旧亮色终端和 Classic 的弱文字对比不足，并加入 WCAG AA 自动断言。
4. **帮助与 FAQ**：底部新增“帮助”入口，涵盖第一次添加 Key、确认切换、三 Key 分工、深度检测/能力体检/修复的区别和常见错误归因。二维码保持原图白底，不做反色；人工求助前明确提醒不要发送 API Key、Token 或未脱敏配置。
5. **更清楚的接入操作**：保存与启用继续分离；列表点击只预选，必须再次“确认切换”；删除必须两步确认并写出目标名称；所有 Provider 都可自定义显示名并在保存后重命名。
6. **版本身份硬门**：正式打包同时核对 Cargo、package.json、Tauri 版本、Windows 窗口标题和页面徽标。任一处不一致即拒绝打包，避免“包是 0.1.6、页面显示 0.1.8”一类分裂身份。

## API Key 切换边界

- 单 Key 切换仍使用 v0.1.5/v0.1.6 已验证的事务：预选 → 二次确认 → Bridge 配置提交/重启 → revision 与一条 `max_tokens=1` 路由验证 → 成功后提交 Windows 设置；失败则回滚。
- v0.1.7 的 UI 改动没有改变 Provider、Bridge patch、验证请求或回滚实现。发布回归会对这段事务做源码切片校验，并复用同一实现的真实 DeepSeek ↔ OpenRouter 往返成功证据，避免只为重复截图再次计费。
- “三个 Key 分工”不是无效 Key 的绕过方式。只有三条接入都可用时才启用；应用整套方案会分别验证三条路由。

## 安装与升级

下载并校验：

- `claude-science-assistant-v0.1.7-release-portable.zip`
- `claude-science-assistant-v0.1.7-release-portable.zip.sha256`

解压到一个新目录，不要只覆盖 EXE。先运行 `1-run-acceptance-preview.bat` 做只读验收，再运行 `3-open-claude-science-assistant.bat`。需要接管/修复 WSL 运行时时，再明确确认 `4-install-runtime-after-preview.bat`。

同一台电脑、同一 Windows 用户通常可继续读取 DPAPI 加密的已保存接入；跨电脑不会携带 Key，需重新添加。升级验收完成前请保留旧目录和私有配置备份。

## 安全与已知边界

- 内置 Claude Science 仍锁定已验证的 0.1.25；运行时更新检查不会自动替换它。
- 深度检测走匿名固定站点，不发送模型请求；能力体检和确认切换会明确提示可能产生的最小真实请求。
- 新增接入中的“测试”会先读模型列表，并可能对多个候选模型以两档输出预算发送多次真实请求；不要在 401/403 或错误 Key 状态下反复点击。
- 端口监听不等于上游 API 可用；`p9_client_rpc` 表示 WSL 挂载 I/O 阻塞，不应被解释成 API 断网。
- 便携包不包含 API Key、OAuth Token、控制 Token 或用户配置；帮助页中的个人微信二维码是公开支持入口，不承载任何凭据。
- 视觉订阅图片请求、全新 Windows/WSL 安装和不同代理/VPN 组合仍建议在目标电脑做一次现场复验。

## 发布验收
